Data Leakage Safeguards Academic Rigor & Methodology
1. Chronological & Stratified Split Train and test partitions are separated strictly before computing statistics. Identifiers (Source IP, Flow ID, Timestamps) are removed to prevent superficial memorization.
2. Training-Fitted Transformers All scalers (RobustScaler), median imputers, and ANOVA F-test feature selectors are fit exclusively on the training partition.
3. Imbalanced Metric Focus For severe class imbalances, accuracy can be misleading. We prioritize macro/weighted F1-score and per-class recall.

System Architecture & Specifications

Technical pipeline specifications, preprocessing architecture, and dataset references.

CIC-IDS2017 Dataset Schema Canadian Institute for Cybersecurity (UNB)

Primary Source: University of New Brunswick (UNB) CIC-IDS2017 benchmark dataset.

Flow Features: Bidirectional statistical features generated by CICFlowMeter, capturing inter-arrival times, packet distributions, header lengths, and TCP control flags.

Attack Scenarios: DDoS, DoS Hulk, PortScan, Botnet C2, and common anomalous network traffic patterns.

Telemetry Type: High-level flow metadata extracted from packet headers without payload inspection.

Data Preprocessing Architecture End-to-End Leakage-Free Pipeline

1. Header Sanitization: Leading/trailing whitespace stripped across all CSV columns.

2. Infinite/NaN Imputation: String and float infinities replaced with NaN and imputed with median values learned strictly on training data.

3. Scaling: RobustScaler applied to handle heavy-tailed network transmission volume outliers.

4. Feature Selection: Top 20 features selected using ANOVA F-statistic (SelectKBest) to ensure high throughput and low latency.

Machine Learning Pipeline Capabilities Integrated Detection & Explainability Suite
Supervised Classification

Random Forest, SVM, KNN, and Logistic Regression with binary and multiclass threat classification.

Unsupervised Outlier Isolation

Isolation Forest recursive tree isolation with calibrated 0-1 outlier scores and K-Means traffic clustering.

Deep Neural Network

Feedforward Multilayer Perceptron (MLP) with ReLU activations and backpropagation optimization.

Explainable AI (XAI)

SHAP TreeExplainer per-record feature attribution and held-out permutation feature importance.

Robust Preprocessing

Data leakage prevention with training-fitted medians, RobustScaler IQR bounds, and ANOVA feature filtering.

REST API Integration

FastAPI endpoints with asynchronous request handling, in-memory model caching, and CSV streaming.

🛡️ Defensive Analysis Platform: Designed for offline network flow analysis and security research. It operates on pre-processed flow telemetry and does not perform active network packet sniffing or automated blocking.
