## 2. Dataset Description & Flow Generation

The CIC-IDS2017 dataset was captured over five consecutive business days (Monday, July 3, 2017 to Friday, July 7, 2017) within a simulated enterprise environment featuring realistic background traffic (HTTP, HTTPS, FTP, SSH, email) and common multi-stage cyber-attack scenarios executed by the B-Profile system.

Raw network packets were captured in PCAP format and converted into bidirectional statistical flows using **CICFlowMeter**. A network flow is defined by the 5-tuple:
$$\text{Flow} = (\text{Source IP}, \text{Source Port}, \text{Destination IP}, \text{Destination Port}, \text{Protocol})$$

### Feature Schema (Selected Core Categories)

| Category | Example Features | Operational Description |
| :--- | :--- | :--- |
| **Identifiers / Endpoints** | `Destination Port` | Identifies service type (HTTP=80, HTTPS=443, DNS=53) or dynamic scanning targets. |
| **Duration & Timing** | `Flow Duration`, `Flow IAT Mean/Std/Max/Min` | Total microsecond lifetime and Inter-Arrival Times between successive packets. |
| **Traffic Volume** | `Total Fwd Packets`, `Total Backward Packets`, `Total Length of Fwd/Bwd Packets` | Quantifies total packets and byte payloads exchanged in forward and backward directions. |
| **Flow Rates** | `Flow Bytes/s`, `Flow Packets/s`, `Fwd/Bwd Packets/s` | Throughput rates. High rates distinguish automated floods from interactive user browsing. |
| **Payload Distributions** | `Packet Length Mean/Std/Variance`, `Average Packet Size` | Statistical dispersion of packet lengths. Attack tools typically generate uniform packet sizes. |
| **TCP Flags** | `FIN`, `SYN`, `RST`, `PSH`, `ACK`, `URG` Flag Counts | Control flags indicating connection initiation (`SYN`), establishment (`ACK`), push (`PSH`), or reset (`RST`). |
| **Behavioral Activity** | `Active Mean/Std/Max/Min`, `Idle Mean/Std/Max/Min` | Periods the flow was actively transmitting vs dormant intervals between pulses (botnet beacons). |

## 3. Attack Categories & Scenario Coverage

1. **BENIGN:** Legitimate baseline traffic generated by normal user browsing, background OS updates, and enterprise services.
2. **DDoS (LOIC):** High-rate distributed volumetric flood overwhelming network bandwidth or service ports.
3. **PortScan:** Reconnaissance probing sequential ports to discover open services and vulnerabilities. Characterized by single forward packets and zero backward responses.
4. **DoS Hulk:** HTTP request flood utilizing dynamic user-agents and randomized query strings to bypass caching and exhaust web server threads.
5. **DoS GoldenEye:** HTTP keepalive and persistent connection exhaustion attack.
6. **Botnet (ARES):** Command-and-control (C2) communication characterized by periodic heartbeat pulses separated by long idle times.
7. **Web Attacks:** Brute Force, Cross-Site Scripting (XSS), and SQL Injection targeting web application interfaces.

## 4. Known Dataset Imperfections & Preprocessing Remedies

| Known CIC-IDS2017 Quirk | Root Cause | Engineering Solution in NetGuard AI |
| :--- | :--- | :--- |
| **Whitespace in Column Headers** | Generated CSVs from CICFlowMeter have leading spaces (e.g., `' Destination Port'`, `' Flow Duration'`). | Applied `col.strip()` across all headers during CSV parsing in `ml/data_loader.py`. |
| **Infinite Values (`Infinity`)** | Dividing packet volume by near-zero flow duration yields $\infty$ in `Flow Bytes/s`. | String and float infinities replaced with `NaN` and imputed with median values learned on training data. |
| **Severe Class Imbalance** | Real network captures have $>80\%$ normal flows and $<5\%$ rare attacks (e.g., Heartbleed). | Stratified train/test splitting; prioritized macro F1-score and per-class recall over accuracy. |
| **Non-Informative Column Leakage** | `Timestamp`, `Source IP`, and `Flow ID` permit models to memorize specific IP addresses instead of learning behavioral dynamics. | Excluded all identification and timestamp fields from the feature matrix prior to training. |

## 5. Synthetic Demonstration Dataset Specification

To ensure NetGuard AI is 100% turnkey, reproducible, and verifiable on student laptops without forcing evaluators to download multi-gigabyte raw PCAP/CSV files, the project includes an offline synthetic dataset generator (`scripts/generate_demo_data.py`).

### Characteristics:
- Conforms strictly to the 68-feature CIC-IDS2017 schema.
- Accurately simulates the multivariate Gaussian and Poisson distributions of normal and malicious network flows:
  - Normal flows exhibit balanced packet lengths, established TCP handshakes (`ACK=1`), and moderate IATs.
  - DDoS flows exhibit packet rates $>50,000\text{ pkts/s}$, asymmetric forward packet dominance, and short durations.
  - PortScan flows exhibit randomized destination ports, 1–2 forward packets, zero backward responses, and standalone `SYN` flags.
  - Bot flows feature periodic high `Idle Mean` simulating C2 beaconing.
- Intentionally embeds 0.5% edge-case `Infinity` and `NaN` values to verify that data cleaning and imputation pipelines work as designed.
- **Important Academic Note:** Synthetic demonstration performance is presented for software and pipeline verification. It should not be represented as real-world operational intrusion detection performance. Real CIC-IDS2017 CSV files can be ingested directly via `scripts/prepare_data.py`.
